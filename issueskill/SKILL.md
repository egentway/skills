# Issueskill

Issue a reusable skill through a reviewable authoring process. Here, "issue"
means produce the skill package, not install it or publish it remotely.

## Create or extract a skill

Read [the authoring process](issue.md) and [the authoring conventions](conventions.md).
Start from the user's brief or the relevant activity in the current conversation.
Do not activate merely because a process seems reusable.

Invocation authorizes discussion and a proposal. Write the proposed skill only
after the user approves that proposal. Activation consent is not write approval.

## Maintain authoring conventions

When the user requests changes to skill-authoring rules, update
[conventions.md](conventions.md) without starting a new skill. Change the process
or this entry point only when the requested change affects them too.

After modifying this skill, verify the affected instructions and commit the change
using the commit policy in [conventions.md](conventions.md).

All links are relative to this skill directory. Install or copy the complete
package when installation is separately requested.
